# 메신저(Slack·Discord)에서 확인할 것 (실제 연결 점검표)

Slack·Discord 연결 코드는 공식 문서(2026-11-13 에 docs.slack.dev 와 docs.discord.com 을 읽음)를 보고 만들었고,
가짜 HTTP·가짜 웹소켓으로만 시험했다(tests/test_messengers.py). 웹소켓 한 겹(jhq/messengers/ws.py)은 이 맥 안의
가짜 서버에 붙여 글·ping·닫힘 코드를 읽는 것까지만 봤다. **실제 Slack 워크스페이스나 Discord 봇에 붙여 본 적은 없다**(토큰 없음).
텔레그램은 예전과 같은 코드라 바뀐 것이 없다(받기 고리만 메신저 층으로 옮김).

## Slack
| # | 해 볼 것 | 기대 | 결과 |
|---|---|---|---|
| 1 | api.slack.com/apps 에서 skills/setup/messengers/slack-app-manifest.yaml 붙여 넣기 | 오류 없이 앱이 만들어진다(필드 이름은 문서에 맞췄지만 Slack 검사기로 돌려 보지 않음) | |
| 2 | 앱 토큰(connections:write)·봇 토큰을 `jarvis secret set slack-app`·`slack-bot` 으로 | 모양 검사(xapp-·xoxb-) 통과 | |
| 3 | `jarvis messenger pair` | DM 을 보낸 사람의 멤버 ID 와 이름(users.info, users:read)이 나온다 | |
| 4 | DM '안녕' | 답이 온다. `message.im` 사건의 channel_type·user 로 대표 확인 | |
| 5 | 다른 사람이 앱에 DM | 아무 답도 없다(버림) | |
| 6 | 봇 자신의 글 | 다시 받아 처리하지 않는다(bot_id 거르기) | |
| 7 | 승인 요청 | Block Kit 버튼(승인·수정·거부)이 붙은 글. 버튼 값은 b:0 꼴 | |
| 8 | '승인' 버튼 | 실행기가 승인으로 바꾸고 글이 고쳐지며 버튼이 사라진다(chat.update 의 blocks: []) | |
| 9 | 같은 워크스페이스의 다른 사람이 그 글의 버튼을 누를 수 있는지 | DM 이라 못 보지만, 눌러도 무시돼야 한다 | |
| 10 | '수정' → 질문 글의 스레드에 답장 | 수정 요청으로 기록된다(thread_ts 가 질문 글의 ts) | |
| 11 | 긴 답(1만 자) | 3500자씩 나뉘어 오고 코드 칸이 깨지지 않는다 | |
| 12 | 사진·PDF 보내기 | inbox 로 받아진다(url_private_download, files.slack.com 만) | |
| 13 | `jarvis notify dm "x" --file 그림.png` | files.getUploadURLExternal → completeUploadExternal 로 올라간다 | |
| 14 | 몇 시간 켜 두기 | `disconnect`(refresh_requested) 뒤 새 주소로 다시 붙는다. 심장박동(받기)이 멈추지 않는다 | |
| 15 | '상태'·'새로'·'멈춰' 한 낱말 | 명령으로 먹는다(`/상태` 는 Slack 이 가로챔) | |
| 16 | 👀 반응 | reactions:write 로 붙었다 떨어진다(실패해도 일은 이어 감) | |
| 17 | 지킴이 알림 | 데몬이 꺼졌을 때 DM 이 온다(conversations.open + chat.postMessage) | |
| 18 | 429 | Retry-After 만큼 기다렸다 다시 | |

## 확인 못 한 것(설계 때 고른 것)
- Slack 의 `message.im` 에서 봇 자신이 보낸 글이 다시 오는지 문서에 분명하지 않아 bot_id·subtype 이 있으면 모두 버린다.
- Slack 파일 공유 사건에 subtype file_share 가 붙는지 문서가 엇갈려 files 칸이 있는지로 본다.
- Slack 은 사람마다 버튼 눌림을 따로 응답할 수 없어(봉투 응답만) '지난 버튼입니다' 같은 말은 DM 한 줄로 보낸다.
- Discord 봇이 서버를 같이 쓰지 않는 사람에게 DM 을 보낼 수 있는지(사용자 설치)는 문서로 확인하지 못해, 서버에 넣는 길만 안내한다.
- Discord 의 `-# 작업용` 작은 글씨(subtext)가 어디서나 보이는지.
