# 내 것으로 고치기

## 규칙
- `~/jarvis/rules/00-나에-맞추기.md` 부터: 이름·호칭·말투·더 받을 승인·하지 않을 일·자주 쓰는 곳.
- 다른 규칙도 편집기로 고치거나 Jarvis 에게 "규칙에 ○○ 더해" 라고 말한다. 한 파일 1만 자 안쪽, 넘으면 나눠 새 번호와 RULES.md 색인 한 줄.
- 늘 읽힐 규칙은 CLAUDE.md 의 `@rules/…` 줄에 더한다(많을수록 매번 읽는 양이 는다. 짧게). Codex 로 돌면 AGENTS.md 가 저절로 따라 바뀐다(고치지 않는다).
- 02-승인·07-비밀값 의 막는 범위를 줄이는 것은 사용자가 직접 고친다.

## 스킬
- 플러그인 스킬(`jarvis:…`)은 업데이트 때 바뀐다. 고쳐 쓰려면 그 폴더를 홈으로 복사해 이름을 바꾼다:
  `cp -R <플러그인>/skills/daily-brief ~/jarvis/skills/my-daily-brief` 뒤 SKILL.md 의 `name:` 을 `my-daily-brief` 로,
  description 에 "jarvis:daily-brief 대신 이것을 쓴다" 한 줄. 플러그인 자리는 `/plugin` 화면이나 `claude plugin details jarvis` 로 본다.
- 제안서·보고서 PPT 스킬(`proposal-deck-kr`)의 법인 정보(`firm.json`)는 플러그인 폴더에 두면 업데이트 때 사라진다. 홈 아래(예: `~/jarvis/data/firm.json`)에 두고
  환경변수 `PROPOSAL_DECK_FIRM` 으로 알려 주거나, 위처럼 스킬 폴더째 홈으로 복사해 쓴다.
- 새 스킬은 Jarvis 에게 "○○ 하는 워크플로 만들어" 라고 하면 스킬 make-workflow 순서로 `~/jarvis/skills/<이름>/` 에 만든다.
- 모양: `SKILL.md`(맨 위 `name`·`description`, 아래 절차) + 선택 `scripts/`·`schedule.yaml`. description 에는 언제 쓰는지와 사용자가 할 말의 예를 쓴다.
  description 안에 `: `(쌍점 뒤 띄어쓰기)를 쓰면 YAML 이 깨진다. 쓰려면 따옴표로 감싼다.

## 예약
- `~/jarvis/schedule.yaml` 의 `상태:` 를 켬/끔으로. 시각은 cron(분 시 일 월 요일). 매분 다시 읽는다.
- 지시 예약에는 긴 글 대신 "스킬 ○○ 을 읽고 그대로" 한 줄.

## 문지기·실행 대상·권한 (hooks/)
- gate.json: `push_ok`(push 해도 되는 내 비공개 저장소 주소), `rm_ok`, `protected_services`·`protected_dbs`, `extra_deploy`, `routes`(이 일은 이 명령으로만).
- targets.yaml: 승인 뒤 실행할 일. 예시(gmail-send·site-deploy)의 주석을 풀어 쓴다.
- permissions.json: 데몬 세션에서 쓸 MCP 도구 허용(예: `mcp__claude_ai_Gmail`), 더 막을 것. 고친 뒤 `jarvis perms build`.
- 사용자는 편집기로 직접 고친다. Jarvis 는 직접 못 고치고 `config-apply` 승인 요청으로 바꾼다.

## 메신저 바꾸기
`/jarvis:setup` 에서 다른 메신저를 고르면(`--messenger slack` 등) 그 메신저의 토큰·대표 id 를 넣고 서비스를 다시 띄운다.
예전 메신저의 토큰은 금고에 남아 있다(`jarvis secret delete …` 로 지움).

## 텔레그램 그룹(선택, 텔레그램만)
DM 하나로도 다 된다. 일을 나눠 동시에 돌리고 싶으면 봇을 넣은 비공개 그룹(토픽 켬)을 만들고 `~/.jarvis-hq/config.json` 의
`telegram.group_id` 와 `telegram.topics`(예: `{"승인": 3, "긴급": 5}`)를 적은 뒤 `/jarvis:setup` 을 다시 돌린다.
'승인' 토픽이 있으면 승인 글이 DM 과 거기 둘 다 가고, '긴급' 토픽이 있으면 실패 알림이 거기로 간다. 그 밖의 토픽은 토픽마다 따로 도는 대화가 된다.
