# 아침·저녁 요약

워크플로다: ① `jarvis brief` 가 재료를 모은다 → ② Jarvis 가 고르고 쉬운 말로 쓴다 → ③ jarvisd 가 올린다.

## 철칙
- 재료는 명령 한 줄로만 모은다. 다른 명령을 따로 돌려 보태지 않는다(빠진 재료가 늘 필요하면 엔진 jhq/brief.py 에 칸을 더하자고 제안).
- 출력에 없는 것은 쓰지 않는다. `못 읽음: …` 은 "○○ 못 읽음" 한 줄로 그대로.
- 승인은 #요청n 으로. 경로·명령은 맨 끝 `⟦작업용⟧` 아래에만.

## 아침
1. `jarvis brief morning` (어제 18:00 이후. 다른 시각이면 `--since 2026-01-31T18:00`)
2. 첫 줄 `아침 요약 · 날짜`. 밤사이 한 일·끝난 실행 요청 → 결정 기다리는 승인(#요청n) → 오늘 할 일. 열 줄 안쪽. 없는 칸은 "없음".

## 저녁
1. `jarvis brief evening` (오늘 09:00 이후)
2. 첫 줄 `저녁 요약 · 날짜`. 끝난 일 → 오늘의 실수와 보완 → 결정 기다리는 승인 → 내일 할 일. 열두 줄 안쪽.
3. '오늘의 실수와 보완' 은 재료의 'memory 에 적힌 것'·'실패·멈춤 줄' 에서 실수와 그 보완만. 없으면 "없음".
4. '치울 만한 작업 폴더' 가 있으면 스킬 jarvis:code-work '작업 폴더 치우기' 대로 정리하고 "작업 폴더 n개 치움" 한 줄.

## 알릴 것이 없을 때
- 아침·저녁은 없어도 올린다("없음"으로).
