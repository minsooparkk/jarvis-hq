# 2단계 근거 검색 — 무엇을 어떻게 찾나

2단계(근거 검색)에서 읽는다. 아래 조문 번호는 출발점 예시다 — 답에 쓰기 전에 반드시 원문으로 확인한다.

## 도구 고르기

| 하려는 일 | 도구 |
|---|---|
| 쟁점별 근거를 한 번에 모으기(조문·위임·판례·해석례·통칙·부칙·별표) | `search_tax` |
| 검색된 근거의 원문 이어 읽기 | `get_evidence` |
| 조문 원문·수치(현행 또는 기준일 판) | `get_article` (`as_of`) |
| 법·시행령·시행규칙 3단 본문 | `get_article_tiers` |
| 조문을 낱말이나 "약칭+조번호"로 찾기 | `search_articles` |
| 적용례·경과조치 | `get_amendments` |
| 판 목록·개정 연혁 | `get_article_history` |
| 시행예정 개정 | `list_upcoming` |
| 판례·심판례 / 해석례만 따로 찾기 | `search_cases` / `search_interpretations` |
| 별표·서식 | `search_annexes` → `get_annex` |
| 조세조약 | `list_treaties` · `search_treaties` · `get_treaty_article` |
| 비세법 참조 법령(민법·상법·근로기준법·주택법 등) | `search_reference_articles` · `get_reference_article` |
| 조정대상지역·투기과열지구 지정 이력 | `get_regulated_area_history` |
| 수록 법령 범위 | `list_laws` |
| 초안 인용 검증 | `verify_citations` (3단계) |

## search_tax 의도 쓰는 법

**법령(law)**
- 결론에 직접 적용되는 조문이 먼저. 시행령·시행규칙은 요건을 실제로 구체화할 때.
- 조문번호가 확실하면 "법령명 제N조", 불확실하면 추측하지 말고 "법령명 + 핵심 문언".
- 묻지 않은 신고·납부 절차로 넓히지 않는다. 반대로 **질문이 절차 자체를 물으면**(폐업·신고·납부·기한·서류·가산세)
  그 절차의 직접 근거 조문을 첫 검색에 넣는다 — 예: 폐업 후 종합소득세면 확정신고 조문(「소득세법」 제70조).
- **기한·"○년 이내"** 판정이면 기산일 조문도 넣는다([timing.md](timing.md)).
- **조세특례제한법의 감면·세액공제·소득공제**를 찾을 때는 공통 제한 조문을 덧붙인다: 중복지원의 배제(제127조),
  최저한세(제132조), 양도소득세·증여세 감면의 종합한도(제133조), 별도 조문인 사후관리·추징(예: 제146조).
  조특법 밖의 비과세·공제(소득세법 제89조, 상증법 공제)에는 붙이지 않는다.
- **비과세·감면 요건 괄호가 "○○은 제외한다"로 일부를 빼면**, 빠진 것의 세액을 셈하는 조문도 찾는다 — 그 대상의 범위·정의 조문과 함께.
  예: 1세대 1주택 비과세의 고가주택 → 범위(「소득세법 시행령」 제156조)와 초과분 양도차익 계산(「소득세법」 제95조, 「소득세법 시행령」 제160조).
  빼는 괄호만 보면 "12억 원을 넘으면 비과세 제외"처럼 전액 과세로 읽히는 답이 나온다.
- 같은 유사어를 되풀이해 의도 수를 채우지 않는다.

**해석례(ruling)** — 문언만으로 사실관계 적용이 불명확할 때. 사실관계의 핵심 요소를 검색어에 넣는다.
- 해석례의 제목·회신은 **법령 어휘**로 쓰여 있다. 사용자가 일상어·상품명으로 물었으면 그 말의 의도 하나와
  법령이 쓰는 말로 바꾼 의도 하나를 **함께** 쓴다: 퇴사 → 퇴직, 월세 → 임대료·차임, 코인 → 가상자산,
  스톡옵션 → 주식매수선택권 행사이익, PG사 정산 → 결제대행 수수료 공급가액, 직원 숙소 → 사택 제공이익,
  프리랜서 강사 → 인적용역 사업소득·기타소득 구분. 결론을 미리 정하는 말은 넣지 않고 요건의 말만 쓴다.
- 사실관계를 요건에 대어 보는 질문(해당 여부·처리 방법·평가 방법)이면 쟁점마다 해석례 의도를 하나 이상 만든다.
- 고르는 순서: 사실관계(거래 구조·당사자 관계)가 비슷한 것 → 같은 조문을 해석한 **최신** 것.
  기획재정부 해석 > 국세청 해석 > 심판례 순으로 무게를 둔다. 발행 연도를 보고 그 뒤 개정으로 실효됐는지 따진다.
  사용자 사안과의 사실 차이를 적어 둔다.

**판례·심판례(case·tribunal)** — 판단기준이 판례로 형성됐거나 해석 충돌이 있을 때, 처분의 적법성·실질판단·사실인정이
쟁점일 때. 해당하면 처음부터 찾는다. 대법원(확립된 판단기준) → 조세심판원(구체 사실 판단) → 하급심(참고) 순.
뽑을 것: 법원이 제시한 판단기준·고려요소, 그 사건의 적용 결과, 사안 비교용 사실 요약. 파기환송은 최종 결론이 아니다.

**비세법 전제** — 상속 지분(민법), 임대차(주택·상가건물 임대차보호법), 회사 설립·합병(상법), 근로자성(근로기준법),
명의신탁(부동산실명법), 특수관계(공정거래법), 중소기업 판정(중소기업기본법) 등이 결론의 전제이면 `get_reference_article`
로 "법령명 제N조"를 읽는다. 번호를 모르면 `search_reference_articles` 로 찾는다. 틀린 번호 추측이 가장 나쁘다.
비세법 조문은 전제일 뿐, 세법상 결론은 세법 조문으로 낸다.

**조세조약(treaty)** — 비거주자·외국법인·원천징수 제한세율·이중과세 조정·고정사업장이 있고 **상대국이 특정**될 때만.
"국가명 + 소득 유형·쟁점"(예: "일본 사용료 제한세율")으로 찾는다. 상대국이 없으면 되묻기 후보다.
조약 쟁점이면 국내법의 원천징수·과세권 조문도 함께 찾는다 — 미체결국이면 국내법만으로 답해야 한다.
대상조세 조문(제2조)과 해당 소득 조문을 함께 읽는다 — 지방소득세 포함 여부를 놓치면 세율 비교가 어긋난다.
검색 0건은 "미체결"이 아니라 "수록 본문에서 확인되지 않음"이다.

**별표·서식(annex)** — 조문이 "별표로 정한다", "서식으로 정한다"로 넘긴 숫자·양식과 **작성방법**이 쟁점일 때
(세율표·내용연수표·기준금액, 신고서·명세서의 란 기재 방법). 조문 본문에는 그 숫자가 없다.
"법령명 + 별표 N" 또는 "법령명 + 별지 제N호서식 + 서식명"으로, 번호를 모르면 "법령명 + 서식명"으로 찾는다.
사용자가 서식 번호나 "○○란"을 지목하면 반드시 찾는다. 란 번호와 기재 규칙은 작성방법 문언 그대로 인용하고,
작성방법 원문을 못 읽었으면 "작성방법 원문 미확인"으로 둔다.

## 찾지 않는 것

질문이 직접 묻지 않는 한 납세지·과세관할·세액계산 순서·신고납부 절차·가산세 계산 방법 조문은 중심 근거로 쓰지 않는다
(리스크로 가산세가 있다고 언급하는 것은 된다). 키워드가 비슷해도 조문상 주체나 효과가 다르면 중심 근거로 쓰지 않는다.
조문 제목에 관련 단어가 있어도 본문이 무관하면 버린다. 준용·의제·귀속·통산처럼 효과를 연결하는 규정은 먼저 본다.

## 다 찾았는지

- 쟁점마다 원문으로 읽은 조문 1건 이상, 판단기준형이면 해석례·판례 1건 이상.
- 시점이 걸렸으면 기준일 판과 부칙을 봤는가. 연혁을 물었으면 구간별 본문을 읽었는가.
- 근거마다 "이 쟁점에서 왜 필요한지" 한 줄로 말할 수 있는가 — 말할 수 없으면 버린다.
