# 1단계 질문 분석 — 상세 기준

1단계(질문 분석)에서 읽는다. 목표는 정답을 미리 정하는 것이 아니라 **믿을 만한 답에 필요한
최소 충분 조사를 설계**하는 것이다. 두 가지가 가장 중요하다:
결론을 바꾸는 것만 만들고(쟁점·가설·되묻기·검색 모두), 필요한 것은 처음부터 만든다.

## 법률해석 원칙

1. 법문의 주체(납세의무자·신청 주체·소득 귀속자)를 먼저 정한다.
2. 요건 → 사실관계 → 효과 순서로 본다. 일반 설명 요청에는 사실관계를 억지로 가정하지 않는다.
3. 명의/실질, 직접/간접, 단체/구성원의 구분은 결론을 바꿀 때만 쟁점으로 삼는다.
4. 문언이 먼저다. 취지만으로 요건·혜택을 넓히지 않는다. 특례·감면은 엄격하게 읽는다.
5. 현행 법령이 기본이되, 거래 시점에 구법이 적용될 수 있으면 그 시점을 핵심 확인 사항으로 둔다([timing.md](timing.md)).

## 분석 깊이

- **원하는 결론 수준부터** 가린다: 일반 설명 / 사실관계에 적용한 결론 / 실행(계산·신고·불복) / 해석 대립·고액 리스크.
- **쟁점**: 서로 다른 법적 요건·효과가 있을 때만 나눈다. 하나로 충분하면 하나.
- **가설**: 사실이나 해석에 따라 결론이 실제로 갈릴 때만. 모양 갖추기용 반대 가설은 세우지 않는다.
  불리한 가설(주택 수가 늘어남, 요건 미충족)을 세우면 **그 불리함을 푸는 특례·예외 갈래**를 다음 가설로 함께
  세우고 그 조문도 찾는다(예: 새 주택 취득으로 2주택 → 일시적 2주택 특례).
- 사용자가 날짜·기한을 직접 제시했으면("○년 ○월까지 팔면") 그 날짜가 어느 기간 규정에서 나왔는지를 가설로 세운다.
  사용자의 날짜를 다른 기준일로 바꿔 읽고 "그런 기준 없다"로 부정하지 않는다.
- **검색 확장 순서**: 직접 적용 조문 → 위임 시행령·시행규칙 → (문언만으로 불명확하면) 해석례 →
  (판단기준·해석 대립·선례가 중요하면) 판례·심판례. 앞에서 충분하면 뒤는 찾지 않는다.
  찾는 자료마다 "그것이 없으면 무엇을 판단할 수 없는지" 말할 수 있어야 한다.

## 사실 정리 — 명시한 사실과 따라 나오는 사실

답이 "~로 전제합니다"를 세우기 전에 딛고 설 사실 목록을 만든다. 사용자가 **명시한** 사실과,
사용자가 쓴 **세무 용어에서 정의상 반드시 따라 나오는** 사실을 함께 적는다. 후자를 빠뜨리면 질문과 반대되는
전제를 세워 결론이 뒤집힌다.

| 사용자 문구 | 반드시 따라 나오는 사실 |
|---|---|
| 비용 부인, 손금불산입당함 | 회사가 그 금액을 **비용으로 계상했다** |
| 조사에서 자산으로 봤다 / 자본적 지출로 봤다 | 회사는 **비용으로 처리했다** |
| 경정청구, 수정신고 | 이미 **신고**가 있었다 |
| 가산세 부과, 고지서, 경정·결정 | **처분**이 있었다(불복 기한이 돈다) |
| 소급 적용, 추징 | 과거 과세기간이 특정된다 |
| 원천징수 당했다 | 소득 지급·수령이 있었고 지급자는 원천징수의무자다 |
| 이자·사용료·대금을 수령한다 / 지급한다 | 받는 쪽이 소득자, 주는 쪽이 지급자(원천징수의무자)다 |
| 세금계산서를 발행했다 / 수취했다 | 발행 = 공급자, 수취 = 공급받는 자 |
| 월세를 못 냈다 | 못 낸 쪽은 **임차인**이다(질문에 "임대인"이라 적혀 있어도) |
| ○○가 사망했다(증여·상속 쟁점) | 사망한 사람이 증여자인지 수증자인지를 그대로 옮긴다 — 증여자 사망은 상속개시·증여재산 가산, 수증자 사망은 다른 쟁점 |
| ○○을 취득하기 **전에** 보유한 / 취득한 **후에** 양도 | 순서가 요건이다. 날짜를 요건 문구 옆에 나란히 적는다 |
| 폐업했다 | 사업자등록이 있었고 폐업일이 과세기간을 가른다 |

규칙:
- 도출은 **용어의 정의상 필연적인 것만**. "아마 그랬을 것"은 도출이 아니라 가설이나 되묻기 후보다.
- **방향을 쟁점 나누기 전에 고정한다.** 지급/수령, 증여자/수증자, 임대인/임차인, 매수/매도, 공급자/공급받는 자,
  대여/차입, 합병법인/피합병법인처럼 "누가 누구에게"가 결론을 뒤집으면 한 줄로 적고 그 위에서 쟁점·가설을 세운다.
  질문에 방향이 없으면 지어내지 않고, 결론이 갈리면 두 방향을 가설로 나눈다.
- **사용자 표현이 스스로 모순되면 되묻지 말고 해석을 정해 진행한다.** 예: 월세를 못 내는 쪽을 "임대인"이라 썼으면
  임차인으로 읽고, 답에 "질문의 '임대인'은 월세를 내지 못한 쪽이므로 임차인으로 읽었습니다"라고 밝힌다.
- **구어 어미를 부정으로 읽지 않는다.** "사업용으로 사용하지", "그 정도는 되지"는 진술이거나 확인 물음이다.
  양쪽으로 읽히면 두 경우를 나눈다.

## 되묻기 기준

**기본은 진행이다.** 빠진 사실이 결론을 바꿔도, 조건부 설명("취득 사유가 매매면 A, 상속이면 B")이 가능하면
되묻지 않고 진행하고 빠진 사실은 답 끝에서 묻는다. 남의 일을 대신 알아보는 사람, 거래 전이라 정보가 없는
사람에게 되묻기는 막다른 길이 된다.

되묻는 경우(조건부 설명조차 불가능할 때만):
- 같은 용어가 서로 다른 제도를 가리켜 어느 쟁점인지조차 정할 수 없을 때(예: "특례 적용되나요?"만 있고 어느 제도인지 모름)
- 갈래가 너무 많아 조건부 서술이 무의미할 때(갈래 2~4개면 조건부로 쓴다)
- 시점 없이는 구법·신법 어느 쪽으로도 쓸 수 없고 찾을 법조차 다를 때

되묻지 않는 경우: 일반 설명 요청 / 조건부 설명으로 충분할 때(대부분) / 빠진 정보가 세부만 바꿀 때 /
법령으로 찾아 확인할 수 있는 것 / 사용자가 사실을 모른다고 했거나 일반적인 답을 원할 때 /
사용자가 조건부 진행을 이미 지시했을 때("확인 안 된 건 표시해 줘", "가정해서") /
질의서 양식을 붙여 넣었고 질의 요지가 완결돼 있을 때 /
"어느 제도를 말씀하시나요"만 묻게 될 때 — 짐작되는 제도가 있으면 그 제도로, 둘 이상이면 주요 갈래별로 조건부로 답한다.

좋은 되묻기는 구체적이다: "두 주택의 취득일과 양도 예정일은 각각 언제인가요?"
나쁜 되묻기: "상황을 더 자세히 알려주세요." 되묻는 이유도 존댓말 완결 문장으로 쓴다("…에 따라 달라집니다.").
한 대화에서 되묻기는 한 번이다. 사용자가 답한 뒤에는 남은 미확인 사항을 "확인 필요"로 두고 본 검토로 간다.

## 이어지는 턴 — 사용자가 준 사실·정정·반박

- **사용자가 준 사실은 확인된 사실이다.** 되묻기에 대한 답, 새 메시지, 앞선 질문에 든 사실을 확인된 사실로 옮긴다.
  이미 답한 항목을 미확인으로 남기거나 다시 묻지 않는다 — 답에서 빠진 항목만 남긴다.
- **"모르겠다·일반적으로"** 라는 답은 미확인으로 두되 조건부로 진행한다(다시 되묻지 않는다).
- **정정**("그게 아니라", "수증자가 아니라 증여자가"): 새 사실이 앞 사실과 앞 답의 읽기를 밀어낸다. 무엇이 바뀌었는지 첫 줄에 쓴다.
- **정정 표현 없이 앞 사실과 어긋나게 읽히면** 한쪽으로 조용히 바꾸지 않는다. 두 읽기를 나란히 두고 결론이 갈리면 갈래로 나눈다.
- **반박**("틀렸다", "맞지 않나", "다른 AI는 …", 사용자가 조문·예규를 짚으며 반대 결론을 댐): 반박 지점을 첫 쟁점으로 세운다 —
  "직전 답의 ○○ 결론과 사용자의 △△ 주장 중 어느 쪽이 근거에 맞는가". 결론을 미리 정하지 않고, 사용자가 짚은 근거와
  직전 결론의 근거를 **둘 다** 찾는다.
- **"가정하고 계산해 달라", "~라고 치고"**: 되묻지 않는다. 가정값을 사실로 적고 세율·공제·과세표준 조문을 첫 검색에 넣는다.
- **"아까 ~라고 말했잖아"**: 앞선 메시지에서 그 사실을 찾아 올리고, 그 사실이 바꾸는 쟁점을 다시 세운다.

## 실제로 있었던 실수 — 같은 실수를 하지 않는다

- 신규 오피스텔과 종전 아파트를 가진 사람의 질문에 "오피스텔이 주택이면 비과세 장애"라는 불리한 가설만 거듭 세우고
  일시적 2주택 특례 갈래는 한 번도 세우지 않아, 사용자가 적은 처분기한(잔금일 + 3년)을 "그런 기준은 없다"고 부정했다.
  → 불리한 가설에는 그것을 푸는 특례 갈래를 짝지어 세운다. 사용자가 적은 날짜는 어느 규정에서 나왔는지부터 찾는다.
- 잔금일과 등기일이 함께 적힌 처분기한 질문에서 취득시기 조문을 한 번도 찾지 않아, 사용자가 단정한 "등기일 = 취득일"을
  그대로 받아 기한을 두 달 늦게 안내했다. → 기간 판정에는 기산일 조문(「소득세법」 제98조, 「소득세법 시행령」 제162조)을 함께 찾는다.
- "A가 D(외국 법인)에게 사용료를 지급"을 "A가 사용료를 받는다"로 뒤집어 소득 구분·외국납부세액공제를 전개했다.
  "증여자 사망"을 묻는 질문에 수증자 사망으로 답했다가 바로잡히자 반대 결론을 냈다.
  "인구감소지역 주택을 취득하기 **전에** 보유한 주택"의 순서를 거꾸로 대어 특례를 부정했다. → 방향과 순서는 쟁점을 세우기 전에 고정한다.
- "관련 비용을 부인당했다"는 질문에 "비용으로 계상하지 않았다"는 전제를 깔아 결론이 뒤집혔다. → 용어에서 따라 나오는 사실을 먼저 적는다.
- 조특법 농지 증여세 감면(제71조) 답이 감면 종합한도(제133조) 없이 "전액 감면"으로 나갔고, 고용·창업 감면을 나열한 답이
  중복지원 배제(제127조)를 빠뜨렸다. → 조특법 감면에는 공통 제한 조문을 함께 찾는다([search-playbook.md](search-playbook.md)).
