# 받아쓰기

녹음은 밖으로 나가지 않는다(맥 안에서만 받아쓴다). 다른 받아쓰기 프로그램을 직접 부르는 길은 문지기가 막는다(길 고정).

## 1. 준비 확인
`jarvis stt doctor` → '준비됨' 이 아니면 멈추고 알린다:
- 사용자가 터미널에서 `brew install ffmpeg whisper-cpp`
- 모델 파일 하나(예: `ggml-large-v3-turbo-q5_0.bin`, whisper.cpp 모델 목록에서 받기)를 `~/.jarvis-hq/models/` 에 둔다.
  다른 자리면 `~/.jarvis-hq/config.json` 의 `extras.stt.model` 에 경로(설정 파일 수정은 사용자가).

## 2. 받아쓰기
- `jarvis stt <파일> [--lang ko] [--out 폴더]` → 글 파일 경로가 찍힌다(기본 `.harness/work/stt/<이름>.txt`).
- 긴 녹음(1시간 넘음)은 시간이 걸린다. 시작 전에 "받아쓰는 중이에요, 몇 분 걸려요" 한 줄.
- 무음·지어낸 인사만 나오면 실패로 알려 준다. 그대로 전한다.

## 3. 정리
- 받아쓴 글을 읽고 요지: 누가(알 수 있으면) · 무엇을 · 약속·기한 · 숫자. 받아쓰기가 확실하지 않은 이름·숫자는 "(확실 아님)" 을 붙인다.
- 화자 구분은 글 흐름으로 추정한 것임을 밝힌다.
- 할 일이 나오면 스킬 jarvis:todo 에 더하자고 제안하거나(되돌릴 수 있으니) 더하고 알린다.
- 원문 전체를 메신저에 옮기지 않는다. 요지와 파일 경로만.
