# 할 일

## 어디에
- 기본: `~/jarvis/.harness/todo.md`. 없으면 만든다. 맨 위 `# 할 일` 한 줄, 그 아래 한 줄에 하나:
  `- [ ] 제목 (기한 2026-02-03) #태그` · 끝나면 `- [x] 제목 (끝 2026-02-01)`
- 할 일 MCP 가 연결돼 있고 사용자가 그쪽을 쓰자고 했으면 그 도구로(rules/00-나에-맞추기 '자주 쓰는 곳' 에 적어 둔다).

## 하는 일
- 더하기: 제목은 동사로 끝나게 짧게("견적서 보내기"). 기한을 말했으면 날짜로 바꿔 적는다. 근거(어디서 나온 일인지)는 괄호 뒤에 한 토막.
- 끝내기: `- [ ]` → `- [x]`, 끝난 날 적기. 지우지 않는다(한 달 넘은 끝난 것은 `.harness/todo-done-YYYY-MM.md` 로 옮긴다).
- 미루기: 기한만 고친다.
- 보기: 기한 지남 → 오늘 → 이번 주 → 기한 없음 순. 숫자 한 줄 + 급한 것 다섯 줄.
- Jarvis 자신이 이어서 할 일(한 턴에 못 끝낸 일)은 `#jarvis` 태그를 붙인다. 아침 요약이 본다.
- 바꾼 뒤 `jarvis log add "할 일 …" --결과 "더함/끝냄"`(자잘한 것은 묶어서 한 줄).

## 하지 않을 것
- 할 일 글 안에 비밀값·계좌·주민번호를 적지 않는다.
- 남에게 보내는 일(독촉 메일 등)은 할 일로 적고, 보내기는 스킬 jarvis:send-mail(승인).
