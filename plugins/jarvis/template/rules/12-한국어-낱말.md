# 한국어 낱말

한국어로 글을 쓸 때 따른다. 대화, 문서, 커밋, 코드 주석 모두 해당한다.

## AI 글로 읽히는 낱말

> 2026-11-12에 Threads에서 반응이 컸던 글 27건과 그 댓글을 읽고 정리한 것이다.
> 출처, 날짜, 반응 수는 `docs/threads-ai-style-sources.md`에 있다. 괄호 안 숫자는 2026-11-12 기준 좋아요 수다.

### 0. 적용 범위

- 문자 그대로의 뜻이나 전문 용어로 쓸 때는 대상이 아니다. 예: 좌표축, 현금흐름, 지배구조, 과세 기준, 네트워크 레이어.
- 추상적인 대상에 은유로 붙일 때만 잡는다.
- 걸린 낱말을 비슷한 은유로 바꾸지 않는다. 가리키는 대상이나 행동을 직접 쓴다.

### 1. 1순위 명사: 0회

| 표현 | 지목된 예 | 고쳐 쓰기 |
|---|---|---|
| 축 | 한 축으로 보겠습니다, ~까지 한 축으로 본다 | A와 B를 같이 다룬다 |
| 결 | 결이 같다, 결이 다르다, 정서의 결 | 비슷하다, 다르다. 무엇이 다른지 쓴다 |
| 갈래 | 두 갈래로 나뉩니다 | 둘로 나뉜다, 두 가지다 |
| 자리 | 자리로 돌아옵니다, ~로 자리합니다 | 돌아온다, 있다 |

근거: @exhibition.hyeon 178 (1티어로 축, 결 지목), @yun_ja_dong 91 (갈래, 자리, 축)과 댓글 20, 12.

### 2. 물리적 은유 명사: 0회

레이어, 척추, 등뼈, 해자, 두께, 토대, 기반 위에 세우다, 천장, 문턱, 제자리, 그 지점, 밀도, 농도, 경로, 게이트.

은유를 빼고 실제 대상을 쓴다. 예: `새로운 가능성의 토대를 마련합니다`는 실제로 가능해지는 일로 바꾼다.

근거: @kargnas 148 (추상적인 대상에 위, 레이어, 척추, 등뼈, 해자, 두께 같은 물리적 은유 사용)과 댓글, @yun_ja_dong 댓글 20, @conbowl 602 (3번), @buildnwrite 221.

### 3. 동사: 문서당 각 1회 이하

| 동사 | 지목된 예 | 고쳐 쓰기 |
|---|---|---|
| ~로 본다, ~로 읽는다 | 한 축으로 본다 | 판단한다, 분류한다. 또는 단언으로 쓴다 |
| 붙는다 | ~이 아니라 ~가 붙는다 | 생긴다, 추가된다 |
| 넓히다, 좁히다 | ~정도로 넓혀도 N건 수준이라 | 범위를 ~까지 늘려도 N건이라 |
| 열다, 닫다, 굴리다, 묶다, 묶이다, 다투다 | 하나로 묶다, ~에 묶입니다 | 합치다, 포함하다, 운영하다, 경쟁하다 |
| 남는다, 갈린다 | ○○만 남는다, ○○로 갈린다 | 결과를 직접 쓴다. 나뉜다, 달라진다 |
| 걷어낸다, 덮는다 | AI 티를 걷어낸다 | 뺀다, 지운다, 가린다 |
| 민다, 간다 | 끝까지 밉니다, 한 단계 더 갑니다 | 계속한다. 다음에 할 일을 쓴다 |
| 버티다, 살아남다 | 살아남는 건 ○○다 | 결과를 직접 쓴다 |
| 뒤집다 | 진단 순서를 뒤집는다 | 바꾸다, 반대로 하다 |
| 던지다 | 프롬프트를 던진다, 질문을 던진다 | 입력하다, 보내다, 묻다 |
| 깔다 | 도구를 깐다 | 설치하다 |
| 갈아끼우다 | 모델을 갈아끼운다 | 교체하다 |
| 녹이다, 튀다, 받다 | 문제를 녹여 버린다, 능력이 튄다, 문제를 도구로 받았다 | 단숨에 해결한다, 두드러진다, 도구로 해결했다 |
| 들어갑니다, 나갑니다, 넘어갑니다 | 진행을 알리는 멘트 | 지운다 |

근거: @kargnas 148, @exhibition.hyeon 178 (2티어: ~로 본다, ~로 읽는다, 흐름, 붙는다), @yun_ja_dong 댓글 20, 12, 4, @buildnwrite 221.

### 4. 굳은 서술 틀: 문서당 각 1회 이하

`~역할을 합니다`, `~로 자리합니다`, `~에 자연스럽게 맞습니다`, `~가 잘 맞습니다`, `~가 딱 맞습니다`, `~을 보장하며`, `~을 반영하며`, `~쪽입니다`, `~쪽으로`, `~상황입니다`, `~하고자 합니다`, `~라고 봅니다`, `~지는 않았습니다`, `흐름 안에서`, `그 위에서`, `가능한 범위 안에서`, `하나만 가져간다면`, `다음 걸음`.

근거: @kargnas 148 (본문 3편), @buildnwrite 221.

### 5. `박다` 계열: 0회

- `박다`와 그 활용형(`박아두다`, `박아둠으로써` 포함)을 저장, 기입, 등록, 고정의 뜻으로 쓰지 않는다. 바꿔 쓸 말은 저장하다, 기입하다, 등록하다, 고정하다. (@exhibition.hyeon 3티어, @buildnwrite 221)
