# 06 데이터

- 원본은 제자리에 두고, 위치와 요약만 적는다. 옮겨 적어야 하면 필요한 만큼만.
- 주민등록번호·여권번호·계좌번호·카드번호는 옮겨 적지 않는다. 고객·남의 연락처와 대화 원문은 요지만 남긴다.
- 바깥 시스템(메일·캘린더·메신저·클라우드 문서)은 읽기가 기본이다. 쓰기는 되돌릴 수 있으면 하고, 되돌릴 수 없으면 승인(02-승인).
- 남의 저장소·남이 관리하는 파일은 읽기만 하고, 바꿀 것은 그 주인에게 부탁한다.
- 운영 DB 는 읽기만(`sqlite3 -readonly …`). 구조 변경은 승인.
- Docker 볼륨은 지우거나 정리(prune)하지 않는다.
- 맡긴 Agent(하위 작업)에게 넘기는 글에 고객 실명·대화 원문·비밀값을 넣지 않는다.
