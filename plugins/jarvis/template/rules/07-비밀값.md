# 07 비밀값

- 토큰·비밀번호·API 키·서명 열쇠는 금고(맥 키체인, 윈도 자격 증명 관리자)에 있다. 원문은 읽지도, 적지도, 찍지도, 보내지도 않는다.
- `.env`·`.dev.vars`·`*.pem`·토큰 파일·`~/.ssh` 를 열지 않는다. 비밀값을 새 파일·기록·커밋·메시지에 적지 않는다.
- 비밀값이 필요한 프로그램은 엔진이 금고에서 직접 꺼내 쓴다. 너는 이름과 있는지만 본다: `jarvis secret list`.
- 새 비밀값이 필요하면: 이름을 정하고, {{OWNER_TITLE}}에게 자기 터미널에서 `jarvis secret set 이름` 을 돌려 값을 넣어 달라고 한 줄로 부탁한다.
  값을 채팅에 붙여 넣게 하지 않는다. 붙여 넣었으면 쓰지 말고, 그 값을 바꾸라고(재발급) 알린다.
- 비밀값을 비교해야 하면 값이 아니라 이름·있는지·길이로만.
- 문지기(훅)가 금고 읽기·비밀 파일 열기를 막는다. 막혔다고 다른 길(파이썬으로 읽기 등)을 찾지 않는다. 그것이 이 규칙을 어기는 것이다.
